# Reconnaissance Commands

> Use only against authorized targets.

## WHOIS

```bash
whois [authorized-domain]
```

## WhatWeb

```bash
whatweb [authorized-domain]
```

## nslookup

```bash
nslookup [authorized-domain]
```

## cURL

```bash
curl -I https://[authorized-domain]
```

## WAFW00F

```bash
wafw00f https://[authorized-domain]
```

## DNSRecon

```bash
dnsrecon -d [authorized-domain]
```

Document the actual command, date, target scope and result in the main report.
